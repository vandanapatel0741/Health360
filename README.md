 # Health360 - Healthcare Risk & Disease Analysis

## Live Project
[Click here to visit Health360 Website](https://vandanapatel0741.github.io/Health360/)

## Tableau Dashboard
[View Interactive Tableau Dashboard](https://public.tableau.com/app/profile/vandana.patel3632/viz/Health360_17933732532810/Story5)
Tableau project to identify high-risk patients for Heart disease, Diabetes and Stroke using age, BMI, BP, cholesterol, glucose, smoking, alcohol, exercise and symptoms (fatigue, chest pain, dizziness).

**Tech:** Tableau Desktop/Public, CSV data source, Python (data prep only)

## Structure
- `data/` raw + cleaned dataset (synthetic, 2000 patients – for learning purposes)
- `scripts/generate_and_prepare.py` data collection + preparation
- `docs/Tableau_Build_Guide.md` full dashboard/story steps
- `web/index.html` web integration (Tableau embed)
